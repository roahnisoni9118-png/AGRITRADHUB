# AgriTradeHub 🌾

AgriTradeHub is a full-stack MERN web application that provides a digital platform for farmers and merchants to manage agricultural products, orders, and reviews.

## 🚀 Features

- User Registration and Login
- User Authentication
- Farmer and Merchant workflow
- Product creation and management
- Product listing and details
- Edit and delete products
- Order management
- Product reviews
- Frontend and backend integration
- REST API based backend

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- Bootstrap
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- REST APIs
- JWT Authentication
